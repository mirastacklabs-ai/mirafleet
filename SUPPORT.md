# Support

mirafleet is open source and maintained by MIRASTACK LABS. Here is where to take what.

| You have | Go to |
|---|---|
| A setup question or "how do I...?" | [Discussions](https://github.com/mirastacklabs-ai/mirafleet/discussions), Q&A |
| An idea | [Discussions](https://github.com/mirastacklabs-ai/mirafleet/discussions), Ideas |
| A bug | [Bug report](https://github.com/mirastacklabs-ai/mirafleet/issues/new?template=bug_report.yml) |
| An early test to report | [Test report](https://github.com/mirastacklabs-ai/mirafleet/issues/new?template=test_report.yml) and [docs/TESTING.md](docs/TESTING.md) |
| A feature request | [Feature request](https://github.com/mirastacklabs-ai/mirafleet/issues/new?template=feature_request.yml) |
| A security problem | [Private report](https://github.com/mirastacklabs-ai/mirafleet/security/advisories/new). Never a public issue. See [SECURITY.md](SECURITY.md). |
| A change you want to make | [CONTRIBUTING.md](CONTRIBUTING.md) |

Read first: the [quickstart](docs/QUICKSTART.md), the [developer guide](docs/guide/README.md)
and the [threat model](docs/THREAT-MODEL.md).

Never paste tokens, keys, registration codes or real hostnames anywhere. mirafleet is pre-1.0
and there is no commercial support or response-time promise; maintainers answer when they can.
